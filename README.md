# Локальный лор

Трекер срабатывания лорбуков. Показывает, какая запись включилась, по какому ключу, от чьего сообщения и сколько примерно токенов она стоит. Сканирование идёт на устройстве. Расширение ничего не отправляет наружу и не дописывает текст в промпт: книги по-прежнему подключает сам клиент.

## SillyTavern

Скопируйте этот репозиторий в `data/<пользователь>/extensions/local-lore` или установите по адресу репозитория. Перезагрузите интерфейс. Панель открывается кнопкой у края чата и пунктом «Локальный лор» в меню расширений.

## Tavo

Импортируйте `tavo/local-lore.tpg`. Панель открывается действием ввода и пунктом боковой панели.
